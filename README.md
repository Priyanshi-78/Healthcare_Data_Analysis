# Healthcare Data Analysis

# 🏥 Healthcare Data Analysis | Python

## Overview
This project focuses on analyzing healthcare data to explore patient demographics, medical conditions, hospital admissions, and treatment patterns using Python.

## Analysis Highlights
- Patient Demographics Analysis
- Medical Condition Analysis
- Hospital Admission Trends
- Treatment and Medication Analysis
- Healthcare Cost Analysis

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Healthcare Dataset (CSV) containing patient details, medical conditions, hospital records, and other healthcare-related attributes.

## Key Insights
- Patient distribution across age groups.
- Common medical conditions.
- Hospital admission patterns.
- Healthcare cost variations.
- Patient treatment trends.

## Learning Outcomes
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Manipulation
- Data Visualization
- Statistical Analysis
